# Orca 协作历程 · 演示分镜脚本

演示页：`docs/demo-orca.html`（自包含单文件，双击 `file://` 即放）。

> **数据为演示合成数据**：结尾快照区读取同目录 `demo-data.js` 暴露的 `window.DEMO_DATA`，该文件为演示生成的合成数据，与实际用量无关。页面只展示快照里已有的字段，不计算、不推测、不编造；若快照文件缺失，数字区自动隐藏，仅保留流程事实。
>
> **协作流程为演示分镜**：leader + 三个可见子代理（pi / claudecode / codex）的分派、并行实现、逐轮 review、bug/fix 回派、逐页截图验收、急停保持现状与凭据恢复，按演示分镜设定呈现，不代表任何实际协作记录。

### 关于画面里的数字（避免误读）

- **04 场景的四行 `before → after` 是本轮流程计数**：可见子代理 3、分派轮次 6、闭环缺陷 4、验收勾选 4；按演示分镜设定，**不是** token 用量、性能指标或任何估算值。画面上已标注「流程计数 · 非用量统计」。
- **05 场景的统计数字不写死在脚本里**：运行时从 `demo-data.js` 的演示数据读取（事件数、总 token、活跃 agent、有记录天数、首末日期、快照时间、数据来源）。取不到就隐藏数字区，只展示流程事实，不编造。
- **BUG-02 / BUG-03 只按 leader 列出的主题呈现**（展示 / 布局主次），未展开未经我核验的修复细节；BUG-01 与 BUG-04 的描述来自本轮可核验的复核与修复记录。

## 二、演示操作说明

### 打开

- **双击 `docs/demo-orca.html`** 即可，浏览器以 `file://` 打开。
- 无需启动服务、无需 `./start.sh`、不占用也不触碰 8765；页面零 CDN / 外部字体 / 图片 / 第三方库。
- 同目录的 `demo-data.js` 是**可选**的演示数据：存在时结尾显示统计数字，缺失时自动降级为只显示流程事实，不会报错。

### 播放控制

| 操作 | 方式 |
|---|---|
| 播放 / 暂停 | 顶栏「暂停 / 播放」按钮，或按 **空格** |
| 重播 | 顶栏「重播」按钮（回到 00 并自动播放） |
| 倍速 | 顶栏下拉：`0.5×` / `1×`（默认）/ `1.5×` / `2×` |
| 定位任意时刻 | 拖动顶栏进度条 |
| 跳场景 | 底栏 6 个场景按钮，或 **← / →** 方向键 |
| 当前状态 | 进度条下方显示场景名与 `已播放 / 总时长` |

### 减少动效

系统开启「减少动态效果」时，页面按 `prefers-reduced-motion` 关闭 CSS 动画与过渡，并**默认暂停**在起始帧；仍可手动播放、倍速或拖动进度条查看各场景（切换为瞬时，无淡入）。

### 两页互跳

- 两页控制条均提供常驻互跳链接：`demo.html` 底栏右侧「了解 Orca →」、`demo-orca.html` 底栏「返回产品演示」，不依赖动画播放状态。
- 场景内另保留剧情式互跳链接（仅在该场景激活时可点）。
- 本轮只新建 `demo-orca.html` 与 `demo-script.md`，未创建也未修改任何现有文件。
